# Конкурс Rox Beauty Bar — як це працює

Учасник сканує QR → вводить свій Instagram → відкриває всі акаунти зі списку → отримує свій **порядковий номер**.
Один нік = один номер (повторно той самий нік отримає свій старий номер).

- Сайт: https://tkaskov.github.io/rbb-konkurs/
- Постер з QR: `Конкурс RBB — постер QR.pdf` у папці RBB (QR веде на сайт і ніколи не змінюється)

---

## Запуск (один раз у день конкурсу)

1. Mac **на зарядці**, з інтернетом, кришку **не закривати**.
2. Двічі клацнути **`Запустити конкурс.command`** у папці RBB.
   Через ~30 секунд у вікні зʼявиться рядок `published https://….trycloudflare.com` — усе працює, вікно можна закрити.

Що відбувається автоматично:
- запускається сервер нумерації на цьому Mac і тунель Cloudflare до нього;
- адреса сервера сама записується на сайт (за ~1 хв сайт оновиться);
- якщо сервер чи тунель впаде — перезапускається сам;
- Mac не засинає, поки сервер працює.

Якщо Mac перезавантажився — просто клацніть `Запустити конкурс.command` ще раз. Номери не губляться.

## Список учасників

Файл **`Учасники конкурсу.csv`** у папці RBB (відкривається в Numbers / Excel):

`№ | Instagram | Дата і час (Варшава) | Мова`

- Папірці для барабана — роздрукуйте колонку «№».
- Витягли номер → знайдіть його у файлі → перевірте в Instagram, що цей нік підписаний на всіх.
- Файл лежить тільки на цьому Mac, в інтернет не викладається.

## Закрити реєстрацію

Створіть у папці RBB порожній файл `.konkurs-closed` (або попросіть Claude) — сторінка одразу почне показувати «Реєстрацію завершено».

## Зупинити

Двічі клацнути **`Зупинити конкурс.command`**. Список учасників лишається у CSV.

### Що де лежить

| Файл | Що робить |
|---|---|
| `index.html`, `styles.css`, `app.js` | Сторінка конкурсу (UA / PL) |
| `config.js` | Адреса сервера (заповнюється автоматично) + список акаунтів |
| `avatars/` | Фото профілів з Instagram |
| `i18n.js` | Усі тексти українською та польською |
| `handle.js` | Перевірка ніка (можна вставити навіть посилання на профіль) |
| `server/` | Сервер нумерації (`index.js`), запис у CSV (`registry.js`), наглядач (`start.sh`) |
| `poster.html` | Постер A4 з QR у стилі RBB |
| `apps-script/Code.gs` | Запасний варіант: бекенд на Google-таблиці |
| `tests/` | `node --test tests/handle.test.js tests/backend.test.js tests/registry.test.js tests/server.test.js` |

Журнали роботи сервера — у папці `RBB/.konkurs-run/`.

### Важливо знати

- Сайт **не може** автоматично перевірити, чи людина справді підписалась (Instagram цього не дозволяє). Кнопка «Отримати номер» відкривається лише після того, як людина відкрила **всі** профілі; справжню підписку перевіряєте у переможця вручну.
- Номер зберігається й на телефоні учасника: якщо він знову відкриє сторінку — побачить свій номер.
- Поки сервер не запущено, сайт працює в **ДЕМО-режимі** (номери тільки на одному телефоні).
