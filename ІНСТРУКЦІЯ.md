# Конкурс Rox Beauty Bar — як запустити

Учасник сканує QR → вводить свій Instagram → відкриває всі акаунти зі списку → отримує свій **порядковий номер**.
Усі номери автоматично записуються в Google-таблицю. Один нік = один номер (повторно той самий нік отримає свій старий номер).

Займе ~15 хвилин. Потрібен лише Google-акаунт.

---

## Крок 1. Google-таблиця (тут будуть усі учасники)

1. Створіть нову таблицю: https://sheets.new — назвіть, наприклад, «Конкурс RBB».
2. Меню **Розширення → Apps Script**.
3. Видаліть усе в редакторі й вставте вміст файлу `apps-script/Code.gs`. Натисніть 💾.
4. Угорі виберіть функцію **setup** → **Виконати** → дозвольте доступ до таблиці
   (Google попередить «неперевірений застосунок» → *Додатково* → *Перейти до проєкту*). Зʼявиться аркуш «Учасники».
5. **Розгорнути → Нове розгортання** → тип ⚙️ **Веб-застосунок**:
   - *Виконувати від імені:* **Я**
   - *Хто має доступ:* **Усі** (Anyone)
   - **Розгорнути** → скопіюйте **URL веб-застосунку** (закінчується на `/exec`).

## Крок 2. Вставити URL у сторінку

Відкрийте `config.js` і вставте URL:

```js
apiUrl: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

Поки `apiUrl` порожній, сторінка працює в **ДЕМО-режимі** (номери тільки на одному телефоні) — для реального конкурсу обовʼязково заповніть.

## Крок 3. Викласти сторінку в інтернет (безкоштовно)

1. Зайдіть на https://app.netlify.com/drop (вхід через Google).
2. Перетягніть **всю папку `konkurs`** у вікно.
3. Отримаєте адресу на кшталт `https://назва.netlify.app` — її можна перейменувати в *Site settings → Change site name* (напр. `rbb-konkurs`).

## Крок 4. QR-постер

Відкрийте `https://ваш-сайт.netlify.app/poster.html` — QR уже веде на ваш сайт.
Натисніть **«Друкувати / зберегти PDF»** (A4, у налаштуваннях друку увімкніть «Фонові зображення»).

> Перед друком відскануйте QR телефоном і пройдіть реєстрацію самі — перевірте, що в таблиці зʼявився рядок.

## Під час конкурсу

- Учасники бачать у таблиці: `№ | Instagram | Дата і час | Мова`.
- Щоб надрукувати папірці для барабана — просто роздрукуйте колонку «№» (або таблицю цілком і поріжте).
- Коли витягли номер — знайдіть його в таблиці й перевірте в Instagram, що цей нік підписаний на всіх.

## Закрити реєстрацію

У `Code.gs` поставте `const REGISTRATION_OPEN = false;` → **Розгорнути → Керувати розгортаннями → ✏️ → Версія: Нова → Розгорнути**.
Сторінка почне показувати «Реєстрацію завершено».

## Змінити список спонсорів

Файл `config.js` → масив `accounts`. Додати: `Object.freeze({ handle: 'нік_без_собачки' }),`. Після змін перезалийте папку на Netlify.

---

### Що де лежить

| Файл | Що робить |
|---|---|
| `index.html`, `styles.css`, `app.js` | Сторінка конкурсу (UA / PL) |
| `config.js` | URL бекенду + список акаунтів |
| `i18n.js` | Усі тексти українською та польською |
| `handle.js` | Перевірка ніка (можна вставити навіть посилання на профіль) |
| `poster.html` | Постер A4 з QR у стилі RBB |
| `apps-script/Code.gs` | Бекенд: видає номери, пише в Google-таблицю |
| `tests/` | Тести: `node --test tests/handle.test.js tests/backend.test.js` |

### Важливо знати

- Сайт **не може** автоматично перевірити, чи людина справді підписалась (Instagram цього не дозволяє). Кнопка «Отримати номер» відкривається лише після того, як людина відкрила **всі** профілі; справжню підписку перевіряєте у переможця вручну.
- Номер зберігається й на телефоні учасника: якщо він знову відкриє сторінку — побачить свій номер.
